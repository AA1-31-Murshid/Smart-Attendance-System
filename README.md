# 📱 Smart Attendance System

A modern, high-performance desktop attendance manager built with Python and CustomTkinter.



## 📥 Direct Download (Windows)
If you just want to use the app without touching any code:
1. Go to the [Releases](https://github.com/YOUR_USERNAME/Smart-Attendance-System/releases) page.
2. Download the `attendance_app.exe` file from the latest version.
3. Run it! (Windows may show a "SmartScreen" warning; click "More Info" -> "Run Anyway").
